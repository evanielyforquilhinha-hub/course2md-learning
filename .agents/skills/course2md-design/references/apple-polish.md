# Current Apple-style desktop direction

The user explicitly requested Taste Skill and an Apple-like whole-product UI on 2026-10-23. This takes precedence over earlier project choices for capsule-shaped ordinary controls, blue section headings and outlined floating legends. Preserve the existing workflows and source palettes.

Ordinary buttons and fields use rounded rectangles; navigation has its own smaller radius. Segmented choices use a neutral inset track and a raised selected surface. Use neutral section headings and controlled accent for actions/focus. Labels remain distinct from regular values and prose. Fields use top labels. Avoid marketing-page decoration, infinite idle motion, heavy gradients and fake transparency. Preserve native system window controls on Windows.

Use Taste Skill as a design-review method adapted to GPUI, not a requirement to migrate to React/Tailwind or replace installed icons/fonts. The shared components remain the implementation authority; inspect their callers in the running native application.
